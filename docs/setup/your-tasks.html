01Register a GitHub AppDo now
unblocks Phase 1 — verified draft PRs on your real repo
The production identity: Conductor acts as its own bot (conductor[bot]) with short-lived, per-install tokens, not a personal token that acts as you. The App-auth code is built and tested; it just needs your App's id, private key and installation.
  1. GitHub → Settings → Developer settings → GitHub Apps → New GitHub App. Name it, set any homepage URL, and for now uncheck "Active" under Webhook (we add webhooks in a later increment).
  2. Repository permissions: Contents = Read and write, Pull requests = Read and write, Commit statuses = Read and write.
  3. Create the App, then Generate a private key (downloads a .pem). Note the App ID shown at the top.
  4. Install App on your one test repo. The URL after installing ends in /installations/<number> — that number is the Installation ID.
  5. Save the .pem somewhere outside the repo and add the four values to .env (below). Tell me when it's in.
add to .env
CONDUCTOR_GITHUB_APP_ID=123456
CONDUCTOR_GITHUB_INSTALLATION_ID=42000000
CONDUCTOR_GITHUB_PRIVATE_KEY_PATH=/Users/you/secrets/conductor-app.pem
CONDUCTOR_GITHUB_REPO=your-org/your-repo
Prefer not to build the App yet? A fine-grained PAT with the same three permissions also works: set CONDUCTOR_GITHUB_TOKEN + CONDUCTOR_GITHUB_REPO instead. The App wins if both are present.
02Tighten the deploy IAMDo soon
unblocks Phase 5 — security hardening
The ConductorDeploy inline policy on conductor-hackathon carries near-admin power on a long-lived key. It got us deployed; it should not stay.
  1. When you are done deploying for the day, detach or delete the ConductorDeploy inline policy from the conductor-hackathon user.
  2. Longer term: move deploys to IAM Identity Center (SSO) with temporary credentials instead of a static access key.
03Cognito user poolLater
unblocks Phase 2 — SSO login & roles
Real sign-in and org scoping. The auth boundary already has the integration point; I wire JWKS validation to whatever pool you create.
  1. Cognito → Create user pool. Add an app client (no secret, for a SPA).
  2. Copy the pool's issuer URL and the app client id into .env.
add to .env (Phase 2)
CONDUCTOR_OIDC_ISSUER=https://cognito-idp.us-west-2.amazonaws.com/us-west-2_XXXX
CONDUCTOR_OIDC_AUDIENCE=your-app-client-id
