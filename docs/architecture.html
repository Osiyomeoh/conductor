Architecture

Conductor

A project manager for teams of humans and agents. Every tool ever built assumes labour is expensive and judgment is free. Agents inverted that. Conductor spends cheap labour to buy back scarce judgment.

Three premises follow from the inversion, and every component below serves one of them.

Done is a claim, not a fact. An agent reports completion confidently and wrongly, all day, at scale. Every tracker on the market records that as success. Conductor requires each commitment to carry, from the moment it is planned, the evidence that would prove it.

Human attention is the scarce resource. Dispatching twelve agent tasks nobody can review by Friday is not throughput, it is debt with a friendly status colour. Work is dispatched only when a reviewer can absorb it.

Waiting is optional. When a project stalls on a decision only a person can make, the plan forks across every plausible answer and builds all of them overnight. You pay three times almost nothing to buy back a night.

Where judgment ends and consequence begins

One line decides the home of every component. Language models do judgment. Deterministic code does consequence. Planning, diagnosis and phrasing a question are ambiguous, so they are Strands agents. Whether something is done, whether an action may reach the world, whose attention is spent, and what a worker has earned are consequential, so they are code with verdicts the model cannot override.

The life of a claim

This is the mechanism the whole product turns on. A worker finishing is not an event that changes state. It is a claim entering a check.

Speculation across an open decision

The largest source of delay in any project is the stretch labelled “waiting on stakeholder”, and no tool measures it. Agent labour is now cheap and parallel, so the wait is optional.

The attention gate

Ready work is not dispatched because a worker is free. It is dispatched because a reviewer can absorb the review it will create.

The team is hired, not configured

An agent teammate is declared as a job description and joins the board beside the people. It starts on probation with no trust, so everything it claims is deep-verified until it earns its way down, and graduation is on evidence rather than time served.

An agent can also belong to a person. It inherits that principal's scopes and can never exceed them, and its output is reviewed by them by default. Delegation moves the labour, not the accountability.

When work queues on a kind nobody is reliable at, Conductor proposes hiring for it as a decision, with a drafted spec attached. Judgment work never counts toward that signal: a queue of decisions means the human is the bottleneck, and hiring there would automate precisely the wrong thing.

Runtime

Built on the Strands Agents SDK against Amazon Bedrock, deployed to Bedrock AgentCore Runtime. The entrypoint uses AgentCore's async task support rather than answering and exiting, so the control loop keeps running between invocations and the runtime reports itself busy while it works. Conductor is a loop a person joins, not a chatbot they open.
